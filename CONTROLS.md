# Controls

## Main Menu
| Action | Keyboard | Mouse | Controller |
|---|---|---|---|
| Navigate Menu || Mouse Hover |
| Press Button || Left Click |
| Zoom In / Out | Up / Down Arrow | Scroll (Up / Down) | Right Stick (Up / Down) |
| Shoot Ball | Space / Enter | Left / Right Click | Left / Right Trigger |
| Crash Game | Any Key | Middle Click | Start |

## Game
### Global
| Action | Keyboard | Mouse | Controller |
|---|---|---|---|
| Move Up | H || Top Face Button |
| Move Down | B || Left / Right D-pad Button |
| Move Left | G |||
| Move Right | D || Left Trigger |
| Look Around || Mouse Movement | Right Stick (Move) |
| Jump | Tab || Right Stick (Press) |
| Advance Dialog | Backspace || Select |

### Per level
#### Interact action
| Level | Action |
|---|---|
| Level 1 | Load level 2 |
| Level 2 | Load Level 1, 2 or 3 |
| Level 3 / Main Menu | Crash the game |

**Keyboard**: Backspace\
**Controller**: Select

#### HastenLevel3Loading action
| Level | Action | Keyboard |
|---|---|---|
| Level 2 | Decrease level 3 waiting time by 0.2sec at every press | Space |
